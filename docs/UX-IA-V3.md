# R/LAB V3 信息架构与界面约束

## 1. 核心定位

R/LAB 的核心不是替代飞书做日常协同，也不是论文管理工具，而是本地优先的科研资料管理系统：

```text
把实验计划、实验批次、过程记录、原始数据、结果和周报放在同一条可追溯链路上
```

AI 的价值是减少记录和整理的重复输入。AI 可以帮助生成实验计划、整理记录、比较历史和生成下一步建议，但所有写入页面的内容仍需人工确认。

## 2. 业务层级

```text
科研工作区
  └─ 科研项目
       └─ 实验计划
            └─ 实验批次（一次真实开展的实验）
                 └─ 过程记录
                      ├─ 结构化参数
                      └─ 原始数据与附件

资料库
  ├─ 实验报告（过程记录的可读视图）
  ├─ 文件中心（所有实验文件的统一检索入口）
  ├─ 周报资料库（本地 PPT/PDF 与反馈时间线）
  ├─ 模板中心
  └─ 物品管理

系统
  ├─ AI 助手
  ├─ API 设置
  └─ 回收站
```

产品采用本地单用户工作区。启动后直接进入，不提供注册、登录、密码、人员管理或管理员界面；内部数据归属字段只用于兼容已有数据库。

## 3. 页面职责

### 实验台

实验台负责项目、实验计划、实验批次和任务的日常管理。它回答“要做什么、正在做什么、下一步是什么”，保留计划进度的可视化，但不承载原始文件的细节列表。

### 实验报告

实验报告是过程记录的阅读层，不是第二套数据录入系统。全局入口左侧使用“项目 → 实验计划 → 实验批次”三级目录，右侧采用卡片流；项目内入口采用左侧记录列表、右侧报告阅读器和上一份/下一份翻页。每条记录只展示最多两张核心结果缩略图，其余内容通过“查看所有原始数据与附件”进入文件中心。

报告导出按钮固定在报告页上方，提供 PDF 和 Word。页面不提供 Word/PDF 导入功能，避免形成另一套难以维护的报告数据源。

### 文件中心

文件中心是实验原始资料的统一收口处，与实验报告共用“项目 → 实验计划 → 实验批次”三级目录，负责范围筛选、搜索、分类、图片预览、批量编辑、批量删除和批量 ZIP 下载。实验报告只链接到这里，不在报告卡片中逐项列出大文件。

### 周报资料库

周报资料库取代“汇报”作为资料管理入口：

- 上传本地 PPT、PDF、ODP 或 KEY 文件；
- 保存报告日期、覆盖周期、标题、所属项目和状态；
- 默认使用 PPT 文件名生成标题，同时保留原始文件名；
- 左侧显示可检索的周报标题列表，右侧展示选中周报的信息；
- 反馈、修改日常和老板意见进入同一条按日期排序的时间线；
- 每份周报都有本地归档目录、下载入口和打开文件夹入口。

现有“从实验生成 PPT”能力保留为资料库中的折叠工具，生成后的文件可再次上传归档。

### AI 助手

AI 助手是全局工作层，不单独占用一个业务页面：

```text
身份与模型状态
  → 当前页面/实验范围
    → 对话与历史会话
      → 快捷提示词
        → 多行输入、附件、API 快捷入口
```

发送前显示即将外发的实验范围、知识库、文件和敏感词检查；写入前显示差异并要求确认。API 设置沿用现有 API 模块，助手只提供快捷入口。

## 4. 关键用户路径

```text
记录实验
  → 过程记录上传结果文件
    → 报告页显示两张缩略图
      → 点击文件夹链接进入文件中心查找完整资料
        → 导出当前报告为 PDF/Word

上传周报
  → 填写日期与项目
    → 本地归档
      → 标注反馈
        → 记录修改日常
          → 按标题或日期再次查阅
```

## 5. 桌面布局规则

- 产品只支持桌面端，设计画布最低宽度为 1180px；不提供手机或平板专用布局。
- 236px 固定侧栏始终可见，顶部工具栏保留全局搜索入口和 AI 助手入口。
- 周报、报告和文件页在桌面画布内使用双栏、目录树或卡片流，不另设移动导航与移动 AI 入口。
- 固定格式区域使用稳定的网格、宽高比和 `min-width`，长标题、路径和文件名使用换行或省略，不允许挤压相邻控件。
- 重要操作使用带文字的主按钮；仅图标按钮必须有 `title` 和 `aria-label`。

## 6. 后续边界

网盘、飞书和协同能力暂不进入核心链路。后续如果接入外部存储，应只扩展文件中心的存储适配层，不能让实验报告直接依赖某一家网盘的目录结构。

### 6.1 职责切分（2026-08-01 确认）

软件收敛成纯管理型工具，只管明白三件事：**实验记录 · 物品 · 周报**。其余交出去：

| 领域 | 归属 | 说明 |
|---|---|---|
| 文献 / 论文 | **Zotero** | 本软件不做文献模块。只借鉴 Zotero「本地文件库 + 元数据 + 一秒检索」的交互思路，**不做任何集成**（不读 `zotero.sqlite`，不接 Web API） |
| 日常事务 / 协同 | **飞书** | 软件内 `/tasks` 保留现状，但不再往这个方向投入 |
| 统计分析 | **已移除** | 历史功能，已删除。总览的四个指标卡是定位性计数，予以保留 |
| 云盘存储 | **现有外部数据链接机制** | 显式化即可：设置里指定「原始数据根目录」（指向已同步的 OneDrive 等本地文件夹），外部链接改存相对路径以便换机。**不写任何云盘 SDK** |
